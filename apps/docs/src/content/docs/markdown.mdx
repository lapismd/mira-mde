## Supported Markdown

| Feature              | Syntax                                                           |
| :------------------- | :--------------------------------------------------------------- |
| Frontmatter          | `---` YAML or TOML frontmatter blocks                            |
| Headings             | `#`, `##`, `###`, through `######`                               |
| Inline formatting    | `**bold**`, `_italic_`, `~~strike~~`, inline code                |
| Links                | `[label](target)`, autolinks, and internal path links            |
| Wikilinks            | `[[Target]]` and `[[Target\|Label]]`                             |
| Markdown embeds      | `![[Target]]` and `![[Target\|Label]]`                           |
| Tags                 | `#tag` and nested tags such as `#mira/docs`                      |
| Lists                | ordered, unordered, nested, and task lists                       |
| Task states          | `[ ]`, `[x]`, and custom task markers such as `[/]`              |
| Blockquotes          | regular blockquotes and Obsidian/Lapis callouts                  |
| Collapsible callouts | `[!note]+` and `[!note]-`                                        |
| Tables               | GFM pipe tables with alignment                                   |
| Grid tables          | reStructuredText-style grid tables                               |
| Code                 | inline code, fenced code, syntax highlighting, and copy controls |
| Math                 | inline `$...$` and block `$$...$$` through KaTeX                 |
| Images               | `![alt](src "title")` with asset resolver support                |
| Raw HTML             | preserved through the Markdown preview pipeline                  |
| Directives           | container, leaf, and text directives from `remark-directive`     |
| Footnotes            | GFM footnotes with backlink output                               |
| Mermaid              | fenced `mermaid` code blocks through `@mira-mde/plugin-mermaid`  |

## Portable Components

The renderer maps portable Markdown to reusable components for frontmatter, callouts, checkboxes, list items, links, wikilinks, tags, images, embeds, code blocks, tables, and Mermaid diagrams.

Application-specific vault panels, workspace sidebars, command registries, and file tree behavior stay outside the portable Markdown packages.
