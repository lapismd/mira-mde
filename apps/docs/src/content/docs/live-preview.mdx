Live preview renders Markdown widgets in the editor without losing the source path. Blocks such as frontmatter, blockquotes, callouts, directives, tables, grid tables, math, Mermaid, embeds, images, and fenced code keep a source toggle so users can return to raw Markdown editing.

## Modes

| Mode           | Behavior                                                               |
| :------------- | :--------------------------------------------------------------------- |
| `source`       | Raw Markdown editing.                                                  |
| `live-preview` | CodeMirror editing with rendered widgets for inactive Markdown blocks. |
| `preview`      | Reading view backed by the same Markdown renderer.                     |
| `split`        | Editor and preview side by side.                                       |

## Source Toggle

Live widgets expose a source affordance when raw Markdown editing is needed. The editor restores the original source range and keeps focus in the CodeMirror surface.

## Live Widgets

| Widget                   | Live-preview behavior                                     |
| :----------------------- | :-------------------------------------------------------- |
| Frontmatter              | Collapsible properties editor with typed value controls.  |
| Callouts and blockquotes | Rendered block widget with source fallback.               |
| Tables and grid tables   | Editable rich table surface with row and column actions.  |
| Code blocks              | Highlighted block widget with language-specific behavior. |
| Math blocks              | KaTeX rendered widget with source fallback.               |
| Mermaid blocks           | Rendered diagram with controls and source fallback.       |
| Images and embeds        | Rendered media/embed preview with source fallback.        |
