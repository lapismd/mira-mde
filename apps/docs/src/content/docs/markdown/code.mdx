## Syntax

````md
`inline code`

```ts
const value = "code";
```
````

Use a language after the opening fence to enable language-specific highlighting.

Use an explicit `text` language for diagrams or other preformatted source that
must remain on one row. In source mode Mira gives these lines a shared
horizontal scroll path instead of wrapping the contents or widening the outer
editor pane.
