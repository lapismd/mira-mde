## Syntax

```md
![Alt text](/path/to/image.svg "Optional title")
![Inline](data:image/png;base64,...)
![Reference][label]

[label]: data:image/png;base64,...
```

Use alt text for accessible descriptions. The title is optional. Data-URI images render without an asset resolver. Paste, drop, and toolbar insert use `imageConfig` on the editor (default upload encodes as a data URL). While an upload is in progress, the editor shows a temporary `![Uploading name…](mira-uploading:…)` placeholder and replaces it when the URL is ready.
