Grid tables use explicit row and column boundaries. They are useful when a table needs row spans, column spans, footer sections, vertical alignment, or block content inside cells.

## Syntax Anatomy

```md
+--------+-------+
| Header | Cell |
+========+=======+
| Body | Cell |
+--------+-------+
```

Use `+`, `-`, and `|` to mark the grid. A line with `=` separates header, body, and footer sections. Missing column delimiters create column spans, and missing row delimiters create row spans.

## Alignment Markers

```md
+:-----:+ +------:+ +---v---+
| center | | right | | bottom|
+-------+ +--------+ +-------+
```

Horizontal alignment is marked with `:`, `>`, and `<` on the grid line above a cell. Vertical alignment is marked with `^`, `x`, or `v`.

These examples are adapted from the syntax documented by [`adobe/remark-gridtables`](https://github.com/adobe/remark-gridtables).
