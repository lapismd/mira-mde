Markdown embeds use wikilink syntax with a leading `!` to render a referenced note or asset inline.

## Syntax

```md
![[Architecture Diagram]]
![[Architecture Diagram|Architecture diagram]]
![[Embedded Note]]
```

Embeds use the configured file adapter (or asset/link resolvers) to find display content for both image assets and Markdown notes.
