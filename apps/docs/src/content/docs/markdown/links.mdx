Markdown links can point to local files, external URLs, or automatic URLs. Mira passes link targets through the configured resolver.

## Syntax

```md
[relative link](notes/markdown.md)
[external link](https://example.com)
https://example.com
```

Applications can provide a link resolver to map local paths into app routes.
