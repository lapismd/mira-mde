Mira's Markdown renderer is shared across live preview, reading mode, embedded preview, and split preview. The default UI imports the complete stylesheet so consumers get the same rendering by default.

Use these pages as focused references. The demo app keeps the combined showcase in one place, while the docs split each feature into a smaller example.

## Basics

| Feature                                   | Syntax                                            |
| :---------------------------------------- | :------------------------------------------------ |
| [Frontmatter](./frontmatter/)             | `---` YAML or TOML property blocks                |
| [Headings](./headings/)                   | `#`, `##`, `###`, through `######`                |
| [Inline formatting](./inline-formatting/) | `**bold**`, `_italic_`, `~~strike~~`, inline code |
| [Lists](./lists/)                         | ordered, unordered, nested, and continued lists   |
| [Task states](./task-states/)             | `[ ]`, `[x]`, and custom task markers             |
| [Blockquotes](./blockquotes/)             | regular and nested quoted blocks                  |
| [Code](./code/)                           | inline code and fenced code blocks                |

## Portable Components

The renderer maps portable Markdown to reusable components for frontmatter, callouts, checkboxes, list items, links, wikilinks, tags, images, embeds, code blocks, tables, and Mermaid diagrams.

Application-specific vault panels, workspace sidebars, command registries, and file-tree behavior stay outside the portable Markdown packages.
