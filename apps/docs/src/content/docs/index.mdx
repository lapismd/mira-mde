Mira MDE is a portable Markdown editor stack. The default UI package gives applications a ready-to-use editor surface, while the lower-level packages stay available for custom shells.

## Packages

| Package                    | Purpose                                                                 |
| :------------------------- | :---------------------------------------------------------------------- |
| `@mira-mde/default-ui`     | Default editor UI, toolbar, feature flags, and imperative mount helper. |
| `@mira-mde/svelte`         | Svelte editor component for custom shells.                              |
| `@mira-mde/react`          | React editor and default UI components.                                 |
| `@mira-mde/preview`        | Rendered Markdown preview components and styles.                        |
| `@mira-mde/plugin-mermaid` | Mermaid rendering extension and controls.                               |
| `@mira-mde/extensions`     | Portable extension contracts, resolvers, modes, and themes.             |

## Markdown Coverage

The demo and docs live examples cover the portable Markdown surface: frontmatter, headings, inline formatting, links, wikilinks, tags, Markdown embeds, lists, task lists, blockquotes, callouts, pipe tables, grid tables, fenced code, syntax highlighting, KaTeX math, images, raw HTML, directives, footnotes, and Mermaid diagrams.

## Install

```bash
pnpm add @mira-mde/default-ui @mira-mde/svelte @mira-mde/extensions
```

```ts
import { createMiraDefaultEditor } from "@mira-mde/default-ui";
import "@mira-mde/default-ui/styles.css";
```
