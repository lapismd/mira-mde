## Enable Mermaid

```ts
import { mermaidExtension } from "@mira-mde/plugin-mermaid";

const extensions = [mermaidExtension()];
```

`MiraDefaultMde` adds this extension automatically when `MiraFeature.Mermaid` is enabled.

## Behavior

- instance-safe render IDs
- responsive SVG layout
- hover controls
- copy source action
- expanded dialog
- pan, zoom, reset, and center controls
- source toggle back to the fenced code block
- optional rough/sketch rendering where supported by the plugin
