The default toolbar is compact, icon-only, and built from declarative action definitions. Applications can use the toolbar inside `MiraDefaultMde`, export it as a standalone toolbar, or add additional toolbar sections.

<ToolbarExample client:only="svelte" />

## Add A Custom Section

```ts
import SparklesIcon from "@lucide/svelte/icons/sparkles";
import type { MiraDefaultToolbarDefinition } from "@mira-mde/default-ui/svelte";

export const toolbars: MiraDefaultToolbarDefinition[] = [
  {
    id: "custom",
    align: "start",
    items: [
      {
        id: "insert-tip",
        label: "Insert tip",
        icon: SparklesIcon,
        run(editor) {
          editor.insertMarkdown("\n> [!tip] Custom action\n> Hello from the toolbar.\n");
        }
      }
    ]
  }
];
```

```svelte
<MiraDefaultMde {toolbars} />
```

## Dropdown Actions

Dropdowns use the same `run(context)` action context as buttons.

```ts
const action = {
  type: "dropdown",
  id: "templates",
  label: "Templates",
  icon: SparklesIcon,
  items: [
    { type: "label", label: "Templates" },
    {
      id: "checklist",
      label: "Checklist",
      run(editor) {
        editor.insertMarkdown("\n- [ ] First task\n- [ ] Second task\n");
      }
    }
  ]
};
```

## Standalone Toolbar

Use `MiraDefaultToolbar` when you build a custom editor shell but still want the default toolbar controls.

```svelte
<MiraDefaultToolbar
  bind:mode
  {value}
  {features}
  {toolbars}
  context={toolbarContext}
/>
```

The standalone toolbar expects a context with `focus`, `getMarkdown`, `insertMarkdown`, `setMarkdown`, `getSelection`, `setSelection`, `setMode`, and readonly helpers.
