## Feature Flags

```ts
import { MiraFeature } from "@mira-mde/default-ui";

const features = {
  [MiraFeature.Mermaid]: true,
  [MiraFeature.Tables]: true,
  [MiraFeature.SplitMode]: false,
};
```

Feature flags apply to the toolbar, extension setup, and valid mode list. A disabled mode is removed from the mode switcher and ignored by `setMode()`.

| Feature flag                  | Controls                                       |
| :---------------------------- | :--------------------------------------------- |
| `MiraFeature.Toolbar`         | Default toolbar visibility.                    |
| `MiraFeature.ModeSwitch`      | View-mode toolbar control.                     |
| `MiraFeature.Formatting`      | Bold and italic toolbar actions.               |
| `MiraFeature.Headings`        | Heading toolbar actions and heading controls.  |
| `MiraFeature.Lists`           | Bullet, ordered, quote, and task list actions. |
| `MiraFeature.Links`           | Link insertion actions.                        |
| `MiraFeature.Tables`          | Pipe-table toolbar and live widgets.           |
| `MiraFeature.GridTables`      | Grid-table toolbar and live widgets.           |
| `MiraFeature.Mermaid`         | Mermaid extension and toolbar actions.         |
| `MiraFeature.Code`            | Fenced-code toolbar actions.                   |
| `MiraFeature.Math`            | Math toolbar actions and rendering.            |
| `MiraFeature.Frontmatter`     | Frontmatter property widget.                   |
| `MiraFeature.Images`          | Image behavior and toolbar availability.       |
| `MiraFeature.Embeds`          | Markdown embed behavior.                       |
| `MiraFeature.Wikilinks`       | Wikilink behavior.                             |
| `MiraFeature.Tags`            | Tag rendering behavior.                        |
| `MiraFeature.SourceMode`      | Source mode availability.                      |
| `MiraFeature.LivePreviewMode` | Live preview mode availability.                |
| `MiraFeature.PreviewMode`     | Reading/preview mode availability.             |
| `MiraFeature.SplitMode`       | Split mode availability.                       |

## Mode and layout continuity

Mira keeps the nearest visible Markdown source line in place when a document
switches between editor and reading modes. Entering split mode maps the already
visible surface to the surface that is being mounted; once split is active,
both panes continue to synchronize by scrollable-range ratio. The current
CodeMirror selection is retained without forcing focus.

Wrapped list items, quoted lists, and plain continuation indentation use
authored-column fallbacks on first paint and browser-measured pixel offsets once
the lines are visible. This keeps content and line-number gutters aligned
across fonts, tabs, ordered-marker widths, and narrow containers.

Explicit `text` fences intentionally keep their source lines unwrapped and use
the editor content area as the horizontal scrolling path:

````md
```text
source --> live-preview --> preview --> split
```
````

The Storybook `Markdown/Layout Parity` fixture exercises these behaviors in
source, live-preview, reading, and split modes at a fixed document revision.

## Slash Commands

The default editor enables a compact slash menu in source and live preview modes. Type `/` on an empty line to insert Markdown snippets for headings, lists, tasks, quotes, callouts, code, math, tables, grid tables, and Mermaid diagrams.

  initialValue={slashCommandsMarkdown}
  mode="live-preview"
  height="18rem"
  sourcePath="slash-commands.md"
/>

Disable built-in snippets by id, or disable all built-ins when an app provides its own list:

```ts
import { MiraFeature } from "@mira-mde/default-ui";

const featureConfigs = {
  [MiraFeature.SlashCommands]: {
    disableDefaultCommands: ["table", "gridTable"],
  },
};
```

Custom snippets use the shared helper from `@mira-mde/extensions`. The `<|>` marker is removed before insertion and becomes the cursor position.

```ts
import { createSlashSnippet } from "@mira-mde/extensions";
import { MiraFeature } from "@mira-mde/default-ui";

const featureConfigs = {
  [MiraFeature.SlashCommands]: {
    commands: [
      createSlashSnippet({
        id: "decision",
        label: "Decision",
        description: "Insert a decision callout",
        group: "Project",
        keywords: ["adr", "choice"],
        markdown: "> [!note] Decision\n> <|>",
      }),
    ],
  },
};
```

Slash commands can still provide a `run(context)` callback for advanced editor-only behavior, but the default UI only ships portable Markdown snippets.

## Markdown authoring

File, embed, heading, and display-text completion uses the existing
`MiraFileAdapter` boundary. `listFiles()` enables target suggestions and
`getHeadings(file)` adds heading suggestions. Mira never imports a vault or
workspace index.

```svelte
<script lang="ts">
  import { MiraDefaultMde } from "@mira-mde/default-ui/svelte";

  const fileAdapter = {
    resolveLink: ({ href }) => files.find((file) => file.path === href) ?? null,
    listFiles: () => files,
    getHeadings: (file) => headingsByPath[file.path] ?? [],
  };
</script>

<MiraDefaultMde
  bind:value
  sourcePath="notes/today.md"
  {fileAdapter}
  authoring={{
    completions: {
      // Optional: replace Mira's shortest unambiguous wikilink formatter.
      formatLink: (target) => formatApplicationLink(target),
    },
    smartPaste: {
      // Optional: apply application-specific rich-text conversion.
      convertHtml: (html) => convertWithApplicationRules(html),
    },
    inputHandlers: {
      // Typographic substitution is deliberately opt-in.
      ellipsis: true,
    },
  }}
/>
```

Defaults:

- `[[…]]`, `![[…]]`, heading, and display-text completion are enabled when
  `listFiles` is available.
- Rich HTML converts to GFM-compatible Markdown, including tables.
- Pasting a URL over selected text wraps the selection as a Markdown link.
- Typing the third backtick scaffolds a fenced block; typing the third leading
  dash scaffolds frontmatter.
- Three-dot-to-ellipsis substitution is disabled unless
  `authoring.inputHandlers.ellipsis` is `true`.

Set `completions`, `smartPaste`, or `inputHandlers` to `false` to disable that
group. Each object also has an `enabled` switch and feature-level switches.

## Extension commands, toolbar items, and styles

Use extension `commands` for actions that should be available from a keybinding, the imperative editor handle, or an extension-contributed toolbar item. The command receives the same framework-neutral runtime context in Svelte and React.

```ts
import { defineMiraExtension } from "@mira-mde/extensions";

export const decisionsExtension = defineMiraExtension({
  name: "decisions",
  commands: [
    {
      id: "insert-decision",
      label: "Insert decision",
      keybindings: ["Mod-Shift-d"],
      enabled: (context) => !context.readonly,
      run(context) {
        context.insertMarkdown("\n> [!note] Decision\n> ", 24);
      },
    },
  ],
  toolbarItems: [
    {
      id: "insert-decision",
      label: "Insert decision",
      command: "insert-decision",
      icon: "wand-sparkles",
      group: "Extensions",
    },
  ],
  styles: [
    "/decisions.css",
    {
      id: "decisions-inline",
      cssText: ".decision-marker { color: var(--interactive-accent); }",
    },
  ],
});
```

String style entries are external stylesheet URLs. Object entries use either
`href` or explicit `cssText`, plus optional `id`/`media`; equal IDs are
reference-counted so multiple editors do not duplicate the style.

The editor handles expose `getCommands()`, `isCommandEnabled(id)`, and
`executeCommand(id)` for command palettes and other consumer UI.

## Imperative Handle

```svelte
<script lang="ts">
  import {
    MiraDefaultMde,
    type MiraDefaultMdeHandle,
  } from "@mira-mde/default-ui/svelte";

  let editor = $state<MiraDefaultMdeHandle | null>(null);

  function insertSummary() {
    editor?.insertMarkdown("\n## Summary\n");
  }
</script>

<MiraDefaultMde bind:this={editor} />
```

The handle exposes `focus`, `getMarkdown`, `setMarkdown`, `getMode`, `setMode`, `getSelection`, `setSelection`, `insertMarkdown`, `setReadonly`, `getCommands`, `isCommandEnabled`, and `executeCommand`.
