## `@mira-mde/default-ui`

```ts
import {
  createMiraDefaultEditor,
  defaultMiraFeatures,
  MiraFeature,
  resolveMiraDefaultFeatures,
  resolveMiraDefaultToolbarItems
} from "@mira-mde/default-ui";
```

| Export | Purpose |
| :--- | :--- |
| `createMiraDefaultEditor` | Imperatively mount the default editor into a DOM node. |
| `MiraFeature` | Stable feature flag names. |
| `defaultMiraFeatures` | Default resolved feature map. |
| `resolveMiraDefaultFeatures` | Merge caller feature flags with defaults. |
| `resolveMiraDefaultToolbarItems` | Resolve built-in toolbar item availability. |
| `resolveMiraDefaultToolbarActions` | Merge custom toolbar actions. |
| `resolveMiraDefaultToolbarDefinitions` | Merge custom toolbar sections. |

## `@mira-mde/default-ui/svelte`

```ts
import {
  MiraDefaultMde,
  MiraDefaultToolbar,
  type MiraDefaultMdeHandle,
  type MiraDefaultToolbarDefinition
} from "@mira-mde/default-ui/svelte";
```

## `@mira-mde/react`

```tsx
import {
  MiraMde,
  MiraDefaultMde,
  MiraDefaultToolbar,
  createMiraDefaultEditor
} from "@mira-mde/react";
import "@mira-mde/react/styles.css";
```

The React package mirrors the default UI API for React applications while preserving the same Markdown behavior and package CSS.

## `@mira-mde/svelte`

```ts
import { MiraMde, type MiraMdeHandle } from "@mira-mde/svelte";
```

Use the lower-level Svelte component when you need a custom application shell.

## `@mira-mde/preview`

```ts
import { MarkdownPreview } from "@mira-mde/preview";
import "@mira-mde/preview/styles.css";
```

Use the preview package when an application needs rendered Markdown without an editable CodeMirror surface.

## `@mira-mde/plugin-mermaid`

```ts
import { mermaidExtension } from "@mira-mde/plugin-mermaid";
```

The Mermaid extension adds preview rendering and live-widget behavior for Mermaid fenced code blocks.
