# Themes

Pass `theme` to `MiraEditor` to select packaged theme tokens. Storybook’s toolbar theme toggle also flips document classes for light/dark chrome.

Supported values: `light`, `dark`, `obsidian`, `system`, `inherit`.

## Usage

<Source language="html" code={`<MiraEditor bind:value theme="obsidian" />`} />
