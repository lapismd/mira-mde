# Mira Editor

`@lapismd/mira-editor` packages a ready-to-use editor shell on top of Mira’s portable Markdown stack.

Start with **[MiraEditor](?path=/docs/mira-editor-miraeditor--docs)** for an interactive playground with a full Properties (Controls) table, then browse:

- **Modes** — source, live preview, preview, and split
- **Themes** — light, dark, and Obsidian tokens
- **Configuration** — readonly, indentation, wrapping, outline, emoji, frontmatter, HTML policy
- **Features** — feature flags and toolbar `featureConfigs`
- **Editor Plugins** — slash commands, block controls, fold / inline headings, image attachments, autocomplete UI, custom toolbars, and `@lapismd/mira-plugin-ai`

Each page follows the same docs pattern as the ui catalog: Usage → Primary → Properties/Controls → Examples.
