# MiraEditor

Default Mira editor shell from `@lapismd/mira-editor`. Compose modes, themes, feature flags, and editor settings through props.

## Usage

<Source
  language="html"
  code={`<script lang="ts">
  import { MiraEditor } from "@lapismd/mira-editor";
  import "@lapismd/mira-editor/styles.css";
</script>

<MiraEditor
  bind:value
  mode="live-preview"
  features={{ mermaid: true, tables: true }}
/>`}
/>
