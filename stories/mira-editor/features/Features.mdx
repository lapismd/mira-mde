# Features

Use `features` and `featureConfigs` on `MiraEditor` to enable or disable packaged capabilities. Edit the object Controls below to experiment.

## Usage

<Source
  language="html"
  code={`<MiraEditor
  bind:value
  features={{
    toolbar: true,
    mermaid: true,
    tables: true,
    "split-mode": false,
  }}
  featureConfigs={{
    toolbar: { items: ["bold", "italic", "heading", "link"] },
  }}
/>`}
/>
