# Table surfaces

Pipe and grid table components share the rendered Markdown token contract while
retaining their rich editor menus, cells, selection, and drag chrome.
`TableReader` renders immutable table fragments with source-row annotations and
an inheritable cell-padding token. Its reader story demonstrates comments
between rows without authoring controls.
