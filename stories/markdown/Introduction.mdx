# Mira Markdown

Storybook is the catalog source of truth for portable Mira markdown features.

Each feature page includes:

- **Preview** — reading surface via `MarkdownPreview`
- **Live Preview** — `MiraEditor` in live-preview mode
- **Source Mode** — `MiraEditor` in source mode
- Syntax notes and colocated MDX docs
- Playwright visual baselines wired through Visual Delta

Images cover path resolution and base64 data URIs. Embeds cover both asset and Markdown-note embeds.

Default editor shell options (themes, modes, feature flags, configuration props) and editor chrome plugins live under **Mira Editor**.
