## Outline Navigation

The default outline uses a floating heading-marker rail. Hovering, focusing, or
clicking it opens the titled navigation panel; choosing an item focuses and
scrolls the matching rendered heading.

## Syntax


## Live preview behavior

In live preview, ATX heading markers (`#`) hide while the caret is off the heading line (`cm-formatting-hidden`). Heading level gutter classes (`cm-gutterHeader-*`) and fold indicators sit in the left gutter so you can collapse sections without leaving rendered mode.
