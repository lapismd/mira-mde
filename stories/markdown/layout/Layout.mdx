# CodeMirror layout parity

This fixture exercises the same geometry-sensitive feature families across
source, live-preview, reading, and split modes. It includes wrapped lists,
quoted lists, continuation paragraphs, tab and space indentation, tables,
widgets, directives, math, Mermaid, and an explicit `text` fence.

Mode changes preserve the nearest visible source line. Split mode continues to
synchronize the editor and preview by scrollable-range ratio.
