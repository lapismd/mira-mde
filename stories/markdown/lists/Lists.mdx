## Configurable List Callouts

Extensions can override built-in markers, add multi-character markers, disable
defaults, select a Mira icon, or provide `renderMarker` for application-owned
icon systems. The same resolved catalog drives preview and live preview;
persistence and settings UI stay with the consumer.
