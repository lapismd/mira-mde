## Property actions and suggestions

<Canvas of={FrontmatterStories.PropertyActions} meta={FrontmatterStories} />

Focus a property name to load configured suggestions. The property icon menu
contains type choices plus cut, copy, paste, and remove. The story injects an
in-memory clipboard, demonstrating the same adapter contract consumers can use
outside secure browser clipboard contexts.
