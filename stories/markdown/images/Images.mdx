# Images

## Syntax

Path image (resolved by `assetResolver` / `fileAdapter`):

```md
![Alt](/mira-markdown-demo.svg "Optional title")
```

Inline base64:

```md
![Alt](data:image/png;base64,...)
```

Reference-style base64 (default when pasting or inserting via the toolbar):

```md
![Alt][label]

[label]: data:image/png;base64,...
```

Paste, drop, and the toolbar image action use `imageConfig` on the editor. See **Default UI → Editor Plugins → Image Attachments**.
