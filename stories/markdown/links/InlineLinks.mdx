# Bundled inline links

Enable local site icons with the existing Mira extension API. The canonical
contract is [Bundled inline links](?path=/docs/mira-specification-portable-markdown-and-editor--docs).
Import the normal `@lapismd/mira/styles.css`; no additional package is needed.
Use Storybook's palette and light/dark controls to review each example's theme.

```ts
import {
  createLinkIconRegistry,
  inlineLinksExtension,
} from "@lapismd/mira/extensions";

const registry = createLinkIconRegistry({
  icons: { github: replacementSvg, companyDocs: companySvg },
  hosts: { "git.example.com": "gitlab", "docs.example.com": "companyDocs" },
  subdomains: { "docs.example.com": "companyDocs" },
});
const extensions = [inlineLinksExtension({ registry })];
```

SVG definitions have `viewBox` and `paths` with `d`, optional `fill`, `stroke`,
`strokeWidth`, `strokeLinecap`, `strokeLinejoin` and `fillRule`. Colors use
`currentColor` or `none`. Use `null` to disable an icon or host mapping,
`fallback: null` to omit unknown icons, and `defaults: false` for custom-only
registries. Replace the registry/extension to update configuration. Registries
copy and freeze input data and never change another editor's icons.

`InlineLink` and `LinkSiteIcon` are exported from `@lapismd/mira/preview` for
standalone Svelte usage, accepting the same optional `registry`. Labelled links
reveal their destination on focus/hover. Icons are decorative and locally
bundled; the extension never fetches metadata or favicons.
