# Doodle dividers

The opt-in `doodleDividersExtension` renders only seeded thematic breaks as
responsive SVG doodles. The native horizontal rule remains in the document as
the accessible separator, and an unseeded rule remains visually unchanged.

## Usage

```svelte
<script lang="ts">
  import { MiraEditor } from "@lapismd/mira-editor";
  import { doodleDividersExtension } from "@lapismd/mira/extensions";

  let value = $state(`<!-- mira-divider:v1:4f32a91c -->
---`);
</script>

<MiraEditor
  bind:value
  mode="live-preview"
  extensions={[doodleDividersExtension()]}
/>
```

## Custom gallery and explicit migration

Consumers can replace the fixed variant set and palette. Existing bare rules
are converted only by the pure helper or the
`mira-doodle-dividers-materialize` command.

```ts
import {
  doodleDividersExtension,
  materializeDoodleDividerSeeds,
} from "@lapismd/mira/extensions";

const markdownWithIds = materializeDoodleDividerSeeds(markdown, {
  createSeed: ({ line }) => 0xc0ffee00 + line,
});

const extension = doodleDividersExtension({
  variants: [customVariant],
  palette: ["#e11d48", "#7c3aed"],
});
```
