# Embeds

Embed another note or asset with Obsidian-style embed syntax. Both image assets and Markdown notes resolve through `MiraFileAdapter`.

## Usage

Docs source shows the public Mira APIs (not story wrapper components).

## Adapter invalidation

<Canvas of={EmbedsStories.AdapterInvalidation} meta={EmbedsStories} />

`watchTarget` refreshes resolution for missing, created, deleted, or renamed
targets. `watchFile` refreshes content for an already-resolved file. Both
callbacks are portable subscriptions owned by the consumer adapter.

## Portable public surfaces

`MarkdownEmbed`, `FileEmbed`, and `NoteLink` expose the same renderer and file
adapter contracts without requiring a full editor instance.

## Syntax

Image asset embed:

```md
![[Architecture Diagram]]
![[Architecture Diagram|Architecture diagram]]
![[Architecture Diagram|320x180]]
```

Markdown note embed:

```md
![[Embedded Note]]
![[Embedded Note#Next Steps]]
![[Embedded Note#^portable-block]]
```
