# Embeds

Embed another note or asset with Obsidian-style embed syntax. Both image assets and Markdown notes resolve through `MiraFileAdapter`.

## Surfaces

Each markdown feature is shown in reading preview (`MarkdownPreview`), live preview, and source mode (`MiraDefaultMde`).

## Syntax

Image asset embed:

```md
![[Architecture Diagram]]
![[Architecture Diagram|Architecture diagram]]
```

Markdown note embed:

```md
![[Embedded Note]]
```
