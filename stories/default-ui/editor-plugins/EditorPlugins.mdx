# Editor Plugins

Live-preview chrome and portable extensions beyond per-feature Markdown pages: slash menus, block gutter controls, fold / inline headings, image attachments, CodeMirror autocomplete slash UI, custom toolbars, and `@mira-mde/plugin-ai`.

## Usage

<Source
  language="ts"
  code={`import { MiraFeature } from "@mira-mde/default-ui/svelte";
import { createSlashSnippet } from "@mira-mde/extensions";
import { aiExtension } from "@mira-mde/plugin-ai";

<MiraDefaultMde
  bind:value
  mode="live-preview"
  features={{ [MiraFeature.SlashCommands]: true, [MiraFeature.BlockControls]: true }}
  featureConfigs={{
    [MiraFeature.SlashCommands]: {
      commands: [createSlashSnippet({ id: "decision", label: "Decision", markdown: "> [!note]\\n> <|>" })],
    },
  }}
  imageConfig={{ imageSyntax: "reference" }}
  extensions={[aiExtension({ run: async () => "…" })]}
/>`}
/>

## Slash Commands

Type `/` on an empty line in source or live preview. Filter with the keyboard, then Enter to insert a snippet. The default UI uses a compact popover menu.

## Image Attachments

Paste, drop, or use the toolbar image action. Default upload encodes files as data URLs and inserts Markdown (reference syntax by default). Configure with `imageConfig`:

- `imageUpload` — async `(file) => url`
- `imageSyntax` — `"reference"` | `"inline"`
- `imageMaxSizeBytes` / `imageMimeTypes` / `onImageUploadError`

There is no separate Attachments API; image attach is part of the Images feature + `imageConfig`.
