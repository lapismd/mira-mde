# Editor Plugins

Live-preview chrome and portable extensions beyond per-feature Markdown pages: slash menus, block gutter controls, fold / inline headings, image attachments, CodeMirror autocomplete slash UI, extension commands/styles, custom toolbars, and `@mira-mde/plugin-ai`.

## Usage

<Source
  language="ts"
  code={`import { MiraFeature } from "@mira-mde/default-ui/svelte";
import { createSlashSnippet } from "@mira-mde/extensions";
import { aiExtension } from "@mira-mde/plugin-ai";

<MiraDefaultMde
  bind:value
  mode="live-preview"
  features={{ [MiraFeature.SlashCommands]: true, [MiraFeature.BlockControls]: true }}
  featureConfigs={{
    [MiraFeature.SlashCommands]: {
      commands: [createSlashSnippet({ id: "decision", label: "Decision", markdown: "> [!note]\\n> <|>" })],
    },
  }}
  imageConfig={{ imageSyntax: "reference" }}
  extensions={[aiExtension({ run: async () => "…" })]}
/>`}
/>

## Image Attachments

Paste, drop, or use the toolbar image action. While uploading, Mira inserts a GitHub-style placeholder (`![Uploading name…](mira-uploading:…)`) and replaces it with the final Markdown when ready. Default upload encodes files as data URLs (reference syntax by default). Configure with `imageConfig`:

- `imageUpload` — async `(file) => url`
- `imageSyntax` — `"reference"` | `"inline"`
- `imageMaxSizeBytes` / `imageMimeTypes` / `onImageUploadError`

There is no separate Attachments API; image attach is part of the Images feature + `imageConfig`.

## Extension Commands, Toolbar Items, And Styles

An extension can declare commands once and expose them through keyboard shortcuts, the imperative editor handle, and framework-neutral toolbar items. `styles` accepts stylesheet URLs or explicit `{ cssText }` descriptors; Mira mounts them once per document and removes them after the final editor using them unmounts.

<Source
  language="ts"
  code={`const decisionExtension = defineMiraExtension({
  name: "decisions",
  commands: [{
    id: "insert-decision",
    label: "Insert decision",
    keybindings: ["Mod-Shift-d"],
    enabled: (context) => !context.readonly,
    run: (context) => context.insertMarkdown("\\n> [!note] Decision\\n> "),
  }],
  toolbarItems: [{
    id: "insert-decision",
    label: "Insert decision",
    command: "insert-decision",
    icon: "wand-sparkles",
    group: "Extensions",
  }],
  styles: [{
    id: "decisions",
    cssText: ".decision-marker { color: var(--interactive-accent); }",
  }],
});`}
/>
