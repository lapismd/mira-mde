# MiraDefaultMde

Default Mira editor shell from `@mira-mde/default-ui/svelte`. Compose modes, themes, feature flags, and editor settings through props.

## Usage

<Source
  language="html"
  code={`<script lang="ts">
  import { MiraDefaultMde } from "@mira-mde/default-ui/svelte";
  import "@mira-mde/default-ui/styles.css";
</script>

<MiraDefaultMde
  bind:value
  mode="live-preview"
  theme="light"
  features={{ mermaid: true, tables: true }}
/>`}
/>
