# `@lapismd/mira-plugin-mermaid`

Mermaid language, preview rendering, source fallback, and expanded diagram
controls for Mira.

```ts
import { mermaidExtension } from "@lapismd/mira-plugin-mermaid";

const extensions = [mermaidExtension()];
```

`@lapismd/mira-editor` enables this extension in its default feature set. See
Storybook and `spec/src/plugins/mermaid.md` for supported behavior.
